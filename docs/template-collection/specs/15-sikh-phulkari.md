# Sikh Phulkari

## Template name

Sikh Phulkari

## User intent

A Punjabi/Sikh expression with sacred symbols chosen separately

## Category

Traditional / Cultural

## Cultural / regional inspiration

Punjab

## Emotional tone

Warm textile geometry

## Palette

#FBF5E9, #69364E, #AE873D, #A45E7B

## Type system

DM Serif Display for editorial display, DM Sans for body; Modern Mono uses DM Sans throughout. Body 10.5–11pt minimum, labels 9pt minimum; headings 11–12pt. Embedded Noto script fonts are chosen from actual text. Never compress type to force one page.

## Page grid

Centered name with optional verified Ik Onkar or Khanda above it, photo at right, and a balanced grid. A narrow Phulkari-inspired strip closes the first sheet.

## Photo mode

square; preserve the full user-approved portrait, with contained fit and manual crop controls. Native face detection can assist crop placement where available.

## Section priority

personal → education → career → family → about → culture → partner → astrology → custom → contact

## Header design

Centered name with optional verified Ik Onkar or Khanda above it, photo at right, and a balanced grid. Sacred header supports: none, ik-onkar, khanda. Default is a property of the explicitly selected template, never of personal data.

## Body design

Reuse normalized visible sections. Narrative and long prose receive a full-width measure; structured sections follow the template grid. Labels are real text, not artwork.

## Footer design

Contact follows the body as a closing section; page number and a quiet rule sit in the protected footer.

## Art safe zones

HEADER_ART_ZONE: Natural measured header; arch minimum 90mm; sacred artwork 32×36mm; never behind body text

BODY_SAFE_ZONE: 18mm inline margins, below measured header, 25mm clear at foot

PHOTO_ZONE: square frame in first header; contain-fit approved image

FOOTER_ART_ZONE: Reserved outer edge or below reading area, first page only

PAGE_2_CONTINUATION_ZONE: Compact running name/rule; 23mm bottom margin; no repeated large artwork

## Short profile behavior

Retain generous spacing and hierarchy. Do not add blank labels or artificial content. Keep the document to one page when its real content fits.

## Long profile behavior

Move an entire section to a fresh page if it fits there. Oversized sections split at groups/rows and then at measured word/grapheme boundaries with a repeated continuation heading. No clipping, overlapping art, or wholesale type shrinking.

## No-photo behavior

Remove the photo slot and expand the name or central arch composition. Additional photos form measured gallery units after the information.

## Missing section behavior

Omit empty sections and compact the grid. Empty culture/astrology never creates a titled box.

## Page 2 behavior

A small ink/accent rule and continuation name only. No page-one deity, portrait medallion, large arch or pavilion is repeated.

## Multilingual behavior

English/Hindi UI remains available; Unicode content supports Marathi, Gujarati, Gurmukhi, Bengali, Tamil, Telugu, Kannada, Malayalam and Urdu through embedded Noto fonts. Logical alignment and an explicit direction option support RTL. Text boxes have no fixed height.

## Negative prompt

No text, pseudo-text, watermark, logos, wedding couple, gaudy saturation, stock clipart, accidental symbols, malformed anatomy, sacred text, or unrelated religious imagery.

## Accessibility notes

Decorations are aria-hidden; document hierarchy is semantic text. Body contrast is checked against paper. Sacred symbols use verified Unicode glyphs/fonts, not generated marks.

## Print notes

A4, zero outer page margin with internal reading margins. Prefer warm light paper and restrained coloured ink. Artwork is optimized separately for screen and PDF, with master originals retained. Lines are at least 0.45pt. Grayscale is reviewed.
